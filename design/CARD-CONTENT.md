# 新闻卡片：原文优先数据契约

2026-09-19。此契约替代早期原型的双语概念解读、摘要、what/why/how/impact 模板。

## 当前交付边界

- 静态接入 12 条真实原始文章，发布时间范围 **2024-10-22—2025-03-12**；不是实时抓取，也不是 2026-09-14 的真实历史日报。
- 保留原型期号、路由 `2026-09-14`，不自动变为今天。原文日期独立展示。
- 仅核对来源页面可访问、标题、短摘录、发布日期，不宣称独立证实性能、商业、科学等发布方主张。
- 本次未接入 AI 生成或自动翻译。原文均为英文；语言开关仅切换界面。分类、Top 5 排序与收藏/已读提示是本站元数据，不是来源引文。

## 卡片顺序

类型 / 技术主题 → 原文标题（标明未改写）→ 可选示意图 → 原文短摘录 → 发布方原文链接与原始发布日期 → 站内阅读时长 / 独立已读与收藏。

标题保留站内详情入口；**原文 · 发布方 ↗** 在新标签页直达对应文章，带 `noopener noreferrer`。搜索、筛选、收藏复用同一原文数据与来源链接。

不展示模型生成的摘要、为什么重要、产品影响或建议；详情同样不保留旧示例分析。详情现支持可选的经批准原文全文与逐图批准的插图，详见 [ARTICLE-READER.md](ARTICLE-READER.md)。当前12条尚无全文数据，仍明确显示原文节选、来源/核对信息与条目导航。

## `originalArticle` 字段

| 字段 | 规则 |
|---|---|
| `title` | 来源页面真实标题，允许统一 HTML 布局空白，不改写或翻译 |
| `excerpt` | 来源正文/摘要中的连续短摘录；可以是句段，不拼接、不补写；空缺时显示“未提供原文摘录” |
| `publisher` | 实际发布方或论文平台及团队；不捏造个人作者 |
| `language` | 原文语言标签，用于标题/引文 `lang` 与 `dir="auto"` |
| `publishedAt` | 原文发布日期；本批为 `YYYY-MM-DD`，不是采集时间、更新日期、评论日期或原型期号 |
| `url` | 具体文章完整 HTTP(S) URL，不接受 javascript/data 或内嵌用户名密码；不得仅链接机构首页 |
| `verifiedAt` | 本次人工辅助核对日期，不表示未来持续监测 |

保留 `title: [original, original]`、`source/sourceEn` 以兼容现有标签/无障碍名称与页面标题；不是两套 AI 译文。`readingSeconds: 30` 为站内短摘录的粗略读时，不代表完整外链文章耗时。

来源文本一律转义后渲染，不信任来源 HTML。无效 `originalArticle` 不当作可引用文章；不回退到生成式 `deck`。

## 来源证据

`news-sources.json` 记录 12 条 URL、标题、摘录、原始日期、日期证据位置、HTTP 状态、核对日期与本次 HTML 的 SHA-256。HTML 原件仅保存在本次验证的临时目录，不把整篇第三方文章复制进仓库。标题和摘录每篇合计不超过 25 个英文空格分词；不用全文抓取代替必要的短引文。

- Anthropic：标题下可见日期。
- Google：页面 `article:published_time`；Research 页面可见日期。
- Hugging Face：正文顶部 Published 日期，不使用贡献者或评论区的 `time`。
- Qwen：文章日期/`article:published_time`；旧官方博客会引导到带同一文章 ID 的新版博客。
- Mistral AI：页面可见日期。
- GitHub：`article:published_time` 与正文可见日期。
- DeepSeek：固定 arXiv **v1**，使用首次提交日期，而非后续版本更新时间。

`tests/verify-news-sources.py` 是可选联网复核，会检查当前 HTTP 状态以及标题/摘录是否仍出现在原页面；不会静默更新原文日期或证据。第三方改版、反爬或网络失败须人工确认，不能编造摘录绕过失败。

## 媒体与状态

主题照片仍为本地 Unsplash 示意图，不代表具体产品或现场。既有 Karpathy 入门视频保留按需加载和外链，明确标注为延伸学习，不是第 11 条 DeepSeek 论文的视频或证据。

Today / Archive / Saved、Top 5 + 7、原 ID、存储键 `afi-editorial-prototype-v1` 保持不变；外链跳转不自动标记已读，收藏不等于已读。仍是本地演示，无账号或云同步。历史收藏/已读 ID 未主动清空，现对应替换后的同编号内容。
