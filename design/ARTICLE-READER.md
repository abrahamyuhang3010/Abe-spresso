# 原文全文阅读器与详情页契约

2026-09-19。**前端已实现可选全文阅读器；原有 12 条仍只有原文短摘录。采集、转载审核、正文导入和生产发布未实现。**

本文件按本次用户要求扩展 `CARD-CONTENT.md` 的详情页边界。卡片仍为原文标题与短摘录，不恢复摘要、翻译或价值解读。详情支持经过批准、具有明确转载依据的原文全文和逐图审核的插图；没有完整数据时保持摘录模式，不以生成文字补齐。

## 1. 页面顺序

1. 返回原列表，保留筛选/收藏上下文。
2. 分类/主题、原文标题、来源角色、原文语言、发布方、原始日期、唯一的原文外链。
3. 阅读范围说明：全文、正文已接入但部分插图不可用、或仅有原文节选。
4. 两个以上原文一级章节时提供可折叠目录。目录用按钮定位并聚焦标题，不修改 SPA 路由、不标记已读。
5. 正文区域：全文模式不再次堆叠卡片摘录；按原文顺序显示段落、标题、强调/链接、列表、引文、表格、代码、插图和图注。
6. 来源与转载说明：来源角色、原始日期、标题/摘录核对时间与范围；全文另含正文快照日期、完整性核对日期及转载说明。
7. 已有延伸学习单列，不冒充原文配图或新闻证据。
8. 独立已读/收藏和上一层返回、下一条、末条完成区。原型期号/路由与存储键不变。

## 2. `articleContent` 可选数据

位置：当前原型 `story.articleContent`。生产契约同义映射为批准条目的 `article_document`；不是 Agent 输出的新闻正文。

```text
schemaVersion: 1
status: "approved"
sourceUrl: 与 originalArticle.url 一致的文章地址
language: 与 originalArticle.language 相同
textComplete: true
capturedAt: YYYY-MM-DD，原文快照日期，不是新闻发布日期
checkedAt: YYYY-MM-DD，正文完整性核对日期
rights:
  basis: permission | open-license | public-domain
  notice: 非空转载/署名说明，必须对应实际材料
  url?: 已确认的许可或转载依据 HTTP(S) 地址
blocks[]: 按原文顺序的结构化内容
```

`status` / `rights` / `textComplete` 是受信出版数据的声明，前端形状检查**不是**授权认定、安全签名或实际完整性核对。生产环境只能由采集、确定性校验和人工审批链路生成。用户提供材料可作为导入起点，但不能仅因“用户提供”就自动判定为公开转载已获准。没有转载依据的全文不得进入公开快照。

### 支持的块

| `type` | 字段 |
|---|---|
| `paragraph` | `content` |
| `heading` | `level: 2 / 3`, `text`；保留相对层级，渲染为正文 section 下的 h3 / h4 |
| `list` | `ordered: boolean`, `items: content[]` |
| `quote` | `content`, 可选 `attribution` |
| `code` | `text`；保留空白，代码区内横向滚动 |
| `table` | `caption`, `headers: content[]`, `rows: content[][]`；每行列数一致 |
| `image` | `src`, `alt`, `width`, `height`, 可选原文 `caption`, `credit`, 独立的 `rights` |

`content` 是纯文本，或按序排列的 `{text, href?, strong?, emphasis?}` 数组。所有字符串转义；链接仅接受无内嵌凭据的 HTTP(S)，新标签页带 `noopener noreferrer`。不渲染原站 HTML、脚本、iframe、事件属性或任意 style。

未知块、结构错误、正文不完整、无批准/转载依据、来源或语言不匹配，均使全文模式不可用；显示既有摘录，不能悄悄丢弃不支持的段落后声称全文。复杂公式、嵌套列表、交互图表等尚无保真解析器；必须扩展结构并核验，不能用模型改写成普通段落绕过。

### 图片边界

- 仅加载 `assets/articles/` 下的本地 PNG/JPG/JPEG/WebP/GIF（允许安全子目录）；生产 Publisher 应提供同源版本化映射。拒绝第三方热链、路径穿越和任意 SVG/HTML。
- 每图单独检查转载依据、署名及尺寸；文章文字许可不自动覆盖插图。
- 宽度随正文容器缩放，高度自适应，`object-fit: contain`；不裁切、不拉伸原图。
- 图注、署名、转载说明保留在 `figure/figcaption`。替代文字不冒充原文图注。
- 未提供图片、缺少逐图许可/署名、非法地址，或实际加载失败时，在原图位置显示可见提示，保留已有图注及署名。不以主题照片、AI 图或空白代替。
- 当前 12 条没有已批准的原文插图；不得将现有首页主题照片移入全文冒充原图。

## 3. 样式与交互

复用 `architecture.css` 中的组件源定义；不新增全局覆盖。Barlow + Noto Sans SC 栈，720px 阅读宽度 token，正文18px、元数据14px、触控44px。表格和代码可局部滚动，不制造页面横向滚动。章节聚焦、滚动区域和所有控件可见键盘焦点。

界面中英文切换不修改原文。文内目录、原文外链、阅读、收藏独立；阅读完成不是自动确认已阅读原站所有材料。
