# v1.2 前端自查与优化

日期：2026-09-17。对象：实际原型 Today / Detail / Archive / Saved 及共用弹窗、设计规范样板。

## 结论

**反模式检查：通过（本次审阅范围）。** 保留暖纸色、品牌深莓、细线和有主次的编辑网格，不采用渐变、仪表盘指标卡、装饰动效或整卡嵌套交互。旧版的核心问题不是缺少装饰，而是字体偏小、样式反复覆盖、图片先于标题和操作密度不一致。

这次优化把“先扫标题，再读摘要/价值，再决定深入或收藏”落实到真实页面，不只调整规范样板。保留三导航、固定12条、Top5+7、每条价值解释、示例属性与独立收藏/已读语义。

## 四个优化重点

### 1. 规范性

- 加载顺序固定为Token → 共享基础组件 → 外壳/控件 → 编辑页面组件。
- Barlow在前、Noto Sans SC指定中文主字体及现有回退不变；不引入任何衬线字体。
- 页眉、导航、内容和页脚共用1200px容器；详情720px阅读列；不通过小字、裁剪或删除内容掩盖布局问题。
- 主按钮为深莓白字，普通操作为轻量文字/描边，品牌SVG及其用途不变。

### 2. 简洁性

- 不增设宣传区、统计卡、侧栏目录或独立视频墙；进度仅一行。
- 筛选继续按需展开，不挤占主要内容；筛选结果的跳转入口对应真实存在的区块。
- 首页将视觉重心交给标题、摘要与价值解释，减少大图片和重复按钮带来的干扰。

### 3. 阅读效率

- DOM与视觉顺序一致：元数据 → 标题 → 配图 → 摘要 → 为什么重要 → 资料/时长/操作。
- Top5保持深入解释，Quick reads保持短文速览；宽屏分离资料操作列，手机自然回流。
- 保留长标题和资料名，不用省略号隐藏关键新闻信息；实际检查了320px长文本、图片/字体失败及200%根字体。

### 4. 新闻属性

- 用“期日、编辑优先级、资料角色、示例说明”建立可理解的信息结构，不靠虚构实时状态或核验徽章。
- 当前固定期日仍是2026-09-14；没有把示例改成真实今日新闻。
- 配图明确为主题插图，不暗示现场证据。详情保留“发生了什么 / 为什么重要 / 理解方式”等编辑结构，事实与示例解读边界清楚。
