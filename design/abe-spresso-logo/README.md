# Abe-spresso · Logo 设计方案

## 方案：The Daily Shot

**品牌名称：Abe-spresso**  
**英文标语：A daily shot of AI.**  
**类别说明：DAILY AI BRIEF**  
**中文辅助文案：每天一小杯，高浓度 AI 新闻。**

这是独立的品牌设计提案。未替换网站根目录的刊头、favicon 或其他线上资源。

### 1. 核心图形

- **负形 A**：在杯身内镂出 Abe 的首字母，避免停留在通用咖啡杯图标。
- **实心浓缩杯**：用紧凑、饱满的轮廓呼应 espresso，也表达“少而精”的内容定位。
- **两道蒸汽**：带来刚冲好的新鲜感与轻微趣味，不强行解释为电路或算法。
- **杯碟横线**：稳定图形重心，呼应现有报刊布局里的细分隔线。
- **语义分工**：图形负责咖啡与个人身份；“每日 AI 新闻”由 DAILY AI BRIEF 和标语明确表达。咖啡杯本身不能独立说明新闻类别。

### 2. 字标

- 固定拼写 **Abe-spresso**，保留大写 A、小写其余字母和中间连字符。
- 字标使用紧凑、有报刊刊头感的 DIN Condensed Bold；类别说明使用 DIN Alternate Bold。
- 宣传标语采用 Georgia Italic，增加编辑式语气。它是独立配套文案，不必出现在每次 Logo 使用中。
- 交付的 SVG 文字已转为矢量路径，无需加载字体即可保持外观；不附带字体文件。若要修改文字，可调整构建源文件后重新生成。

### 3. 配色

直接沿用当前网站色值，不把网站改成棕色咖啡馆风格。

| 用途 | 名称 | 色值 |
| --- | --- | --- |
| 品牌强调色 | Shot Red | `#BD2926` |
| 主字标 | Ink | `#20211F` |
| 浅色背景 | Paper | `#FFFEFD` |
| 辅助底色 | Warm Gray | `#F5F4F0` |

### 4. 使用规则

- **网站桌面刊头**：红色图形 + 黑色字标 + DAILY AI BRIEF；英文标语可以独立放在右侧。
- **移动端刊头**：空间不足时使用 `logo-horizontal.svg`，移除小号类别说明。
- **头像 / 应用图标**：红底白图形，使用 `logo-app-icon.svg`。
- **16–32 px favicon**：使用专门简化的 A 字母版；去掉咖啡杯、杯碟和蒸汽，避免小尺寸细节糊成一团。
- **深色背景**：用反白版，不给红色版本临时添加描边或发光。
- **黑白场景**：使用单色版，不转换为灰色渐变。
- **留白建议**：Logo 四周至少保留图标高度的四分之一。文件本身的透明边距不等于完整安全区，排版时仍应留白。
- **尺寸建议**：带类别说明的主 Logo 优先用在 320 CSS px 及以上；窄屏优先不带说明版。实际输出仍应按字号、屏幕与印刷条件检查。
- 不拉伸，不旋转，不添加阴影、渐变或额外“AI 星芒”，不随意改变图形与字标比例。

- 已检查 SVG 结构、PNG 图形边界和透明通道；主 Logo 未出现裁切。
- 未对现有网站进行 Logo 替换或公开发布。
