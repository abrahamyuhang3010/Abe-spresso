# Abespresso 前端设计规范

**版本：1.2 · 2026-09-17 · 状态：新增及重构页面的设计基线**

> 现代科技编辑部，而不是复古报纸，也不是 AI 工具仪表盘。以中英文无衬线排版、明确的编辑优先级和可信的来源呈现，让读者在约十分钟内读完一份有边界的 AI 日报。

> 2026-09-19 原文优先修订（最高优先）：12 条内容改为历史真实原文。卡片与详情均不生成摘要、价值解释或产品解读。原文标题 + 短摘录 + 发布方 + 真实发布日期 + 直达原文链接；中英文切换不翻译原文。具体数据契约与核对证据见 `CARD-CONTENT.md`、`news-sources.json`。原型日期/路由不变，不冒充当天新闻。

## 0. 使用与范围

- 本文是设计决策规范；`tokens.css` 是数值的唯一来源；`components.css` 是可复用基础组件；`styleguide.html` 是可打开的视觉与交互样板。
- 后续原型先读本文，复用现有组件，再编写页面。不能把参考站截图当成逐像素目标，也不能自由增加第三套字体或装饰色。
- 用户本次称品牌为 **Abespresso**；规范以此为系统名称。现有对外字标 **Abe-spresso** 和标语 **A daily shot of AI.** 暂时保留，本轮采用用户提供的咖啡杯 Logo，不重绘、不改名。
- v1.2 覆盖实际原型的刊头、导航、Top 5、速览、详情、归档、收藏和弹窗：统一字号、间距、控件与响应式；同步样板及回归测试。**这不是全站无障碍认证；CJK 字体分片、跨浏览器和真实缩放验收仍有边界，见 VALIDATION.md。**
- Logo 设计历史文件、ZIP 快照是历史资产，不以新规范追溯改写；新的 UI 不得从它们复制旧字体规则。

| 观察对象 | 本次观察 | Abespresso 的转化 | 明确不照搬 |
| --- | --- | --- | --- |
| Reuters | 无衬线标题、横向导航、主新闻/栏目新闻层次、时间元数据、细线分隔、浅色内容区域 | 一个主视觉重点；信息优先级靠字号、栏宽和留白；来源和时间可查 | 广告占位、行情条、全站栏目数量、商标、付费墙 |

## 2. 体验原则

1. **判断先于数量。** 首屏能辨认期号、主新闻、精选入口；不是先看宣传标语和统计数字。
2. **可信先于炫技。** 事实、编辑解读、推测、来源角色要分清；不靠霓虹、电路背景或机器人插画表达科技感。
3. **同义同形。** 同一语义只用一种字号、按钮样式和状态表达；不是每个版块各设计一套。
4. **中文优先，中英同质。** 不以缩小中文换取英文版布局对齐。切换语言后允许自然增高。
5. **阅读有终点。** 全站只有一处当期进度主入口；整期完成需确认，之后可逐条切回未读，收藏与已读相互独立。
6. **结构先于容器。** 资讯默认无圆角卡片、无投影，用分隔线与空间组织；浮层才使用层级阴影。

## 3. 字体与双语排版（强制）

### 3.1 字体选择

| 角色 | 英文 / 数字 | 简体中文 | 字重 |
| --- | --- | --- | --- |
| 字标、新闻标题、栏目标题 | **Barlow**，常规字宽无衬线 | **Noto Sans SC**，无衬线黑体 | 700 |
| 导航、按钮、重点标签 | Barlow | Noto Sans SC | 600 |
| 摘要、正文、元数据 | Barlow | Noto Sans SC | 400 |
| 代码片段（非新闻正文） | SFMono-Regular / Consolas | 必要时系统回退 | 400 |

选择逻辑：Barlow 的简洁字形适合技术报道中的英文术语、型号和数字；Noto Sans SC 提供清晰均衡的中文黑体结构。科技感来自清晰的字形、层级与网格，而不是过窄、过细或装饰性字体。以上是本项目的设计判断。

```css
font-family: "Barlow", "Noto Sans SC", "Source Han Sans SC",
             "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif;
```

- **英文必须在字体栈前。** 中文字体也可能包含拉丁字形，放在最前会使 Barlow 不生效。
- 全部 UI 标题和正文禁止 `serif`、Georgia、Times、Songti、STSong、Noto Serif SC。禁止将“新闻感”等同于宋体标题。
- 中文不使用斜体强调；用 600 字重。型号、公司名保留原始大小写，禁止把整条英文标题强制全大写。
- 中文标题字距 `0`；英文大标题 `-.02em`。仅英文短分类标签允许 `.06em` 和大写；不得套用中文。
- 一个控件只显示当前语言，固定品牌与技术术语除外。示例页的中英对照是展示用途，不是生产界面的双语堆叠模板。

### 3.2 字号、字重、行高

以默认根字号 16px 作为说明，实际实现用 `rem`，不把根字号锁为 16px，更不能设为 62.5%。

| Token | 默认像素参考 | 字重 / 行高 | 适用范围 |
| --- | --- | --- | --- |
| `--ab-text-page` | 32–48 | 700 / 1.35 | 每页唯一 h1；流式 |
| `--ab-text-lead` | 28–40 | 700 / 1.35 | 当期唯一主新闻；流式 |
| `--ab-text-section` | 32 | 700 / 1.35 | 栏目标题、长文 h2 |
| `--ab-text-title` | 24 | 700 / 1.35 | 普通精选、速览标题、长文 h3 |
| `--ab-text-reading` | 18 | 400 / 1.85 | 详情正文 |
| `--ab-text-body` | 16 | 400 / 1.75 | 原文摘录、说明、输入 |
| `--ab-text-meta` | 14 | 400 或 600 / 1.5 | 来源时间、导航、按钮、标签标题 |
| `--ab-text-caption` | 12 | 400 / 1.5 | 图片署名、非交互徽标、次要注释 |

英文标题行高可降到 1.2；英文正文推荐 1.65–1.75，中文长文保留 1.85。移动端不缩小正文与操作文本；允许主标题流式变小，仍不得低于上述下限。

**禁止：** 9–11px 标签、12px 摘要、正文整段 600/700、标题强制固定高度、为齐底截断引文含义。

### 3.3 行长与断行

- 详情阅读栏上限 `45rem`（720px），18px 中文约 35–40 字/行；英文通常 55–75 个字符/行，依字体实测。`ch` 不等于中文字数，中文不能机械套用 65ch。
- 中文默认自然换行，不使用 `word-break: break-all`。长 URL / 不可断术语局部 `overflow-wrap: anywhere`。
- 日期、版本号、价格使用 `font-variant-numeric: tabular-nums`；完整 ISO 时间放入 `<time datetime>`。
- 列表标题原则上不截断，允许 2–4 行，超长需内容编辑而不是隐藏事实；卡片不固定等高。
- 只在确有详情入口时允许摘要最多 3 行；详情、来源、错误、价值说明禁止截断。

### 3.4 字体交付状态与性能

- 已随仓库提供 Barlow 400/600/700 的 TTF 与 OFL 文件，`font-display: swap`，无第三方字体请求；这是原型交付，正式发布转为 WOFF2。
- **Noto Sans SC 是指定中文主字体，但本次未附完整 CJK 字库。** 本机安装时使用，否则落到思源黑体 / 苹方 / 微软雅黑，再到系统无衬线。样板不会声称所有设备都已显示 Noto Sans SC。
- 上线前补充经过许可确认的 Noto Sans SC WOFF2 分片与 `unicode-range`，覆盖动态文章字符；禁止只抽取当前 12 条示例字形作为正式字库。
- 中文字体按需分片、不预载完整 CJK 文件；英语优先加载 400/700，600 按需。发布预算：首屏实际字体传输总量目标 ≤ 300KB；未达到需记录原因而非假称通过。
- 断网或字体请求失败时仍应可读、不出现方框；首次切换与字体替换无明显跳动。度量回退参数必须实测，禁止编造 `size-adjust` 数值。

## 4. 色彩、形状与图标

### 4.1 品牌来源与角色

v1.1 以用户提供的两份 SVG 为唯一品牌色依据，替代 v1.0 的旧红色。两份资产原样保留，不调整路径、颜色或比例。

| 原始颜色 | Token | 来源 | 使用边界 |
| --- | --- | --- | --- |
| `#F50057` | brand | Logo 杯身、Icon 背景 | 品牌识别、进度填充、选中下划线；不用作普通白字按钮底色 |
| `#AD1457` | brand-deep / accent | Logo 杯柄与杯碟 | 主按钮、链接、选中文字与重要标签 |
| `#BCAAA4` | steam | Logo 蒸汽 | 装饰色与暖中性色的生成起点，不作正文、元数据或控件边界 |

**设计方向：品牌洋红 + 深莓行动色 + 暖咖啡中性色。** 科技感仍来自无衬线与编辑层级；不靠大面积荧光粉、咖啡纹理或渐变表达品牌。阅读区域约 85–90% 保持中性背景是视觉指导，不是机械像素配额。

### 4.2 语义色与派生方法

以蒸汽色的 OKLCH 色相（约 39.35°）为中性色起点，调节明度与低色度生成阅读色阶；行动悬停降低深莓色明度，浅底降低色度并提高明度。最终以十六进制写入 Token，保证与 SVG 原色匹配且可复现。语义状态色不强行套用品牌色。

| 语义 Token（省略 `--ab-color-`） | 值 | 用途 |
| --- | --- | --- |
| paper | `#FEFBFA` | 暖纸白主背景 |
| surface | `#F6ECE9` | 辅助背景、缺图占位 |
| ink | `#2E2421` | 咖啡墨色标题、正文、强分隔 |
| muted | `#73625C` | 次要信息，不再降低 opacity |
| rule | `#E4D6D1` | 装饰性分隔线，不作控件边界 |
| control-border | `#8B7972` | 输入与非主按钮边界 |
| accent / accent-hover | `#AD1457` / `#920046` | 主行动、选中 / 悬停 |
| accent-soft | `#FDEFF2` | 选中弱底色，搭配 accent 文字 |
| on-accent | `#FFFFFF` | 深莓主按钮文字，不是大面积页面底色 |
| focus | `#24647B` | 蓝青键盘焦点，非第二品牌色 |
| success / success-soft | `#246247` / `#EDF4EF` | 完成状态 |
| warning / warning-soft | `#80551C` / `#FAF1E5` | 待核验、提示 |
| danger / danger-soft | `#B3261E` / `#FCEEEB` | 错误和失败，必须配文字 |
| overlay / media-overlay | `rgb(46 36 33 / 48%)` / `rgb(46 36 33 / 72%)` | 弹窗遮罩 / 媒体文字衬底 |
| image-label | `rgb(254 251 250 / 94%)` | 图片署名衬底，搭配 ink |

### 4.3 组合、状态与可读性

- 普通文字目标 ≥4.5:1，大文字及必要非文本边界 ≥3:1；测试具体组合，不能声称任意搭配均合格。
- **白字 / brand = 4.18:1，不能用于普通字号按钮。** 主按钮必须为 on-accent / accent（6.97:1），悬停改 accent-hover。Logo 的白色 A 属于原始品牌图形，不据此推导 UI 文本可用性。
- accent / paper = 6.77:1；accent / accent-soft = 6.24:1；muted / surface = 4.98:1；control-border / paper = 4.02:1。steam / paper 约 2.16:1，仅装饰使用。
- 选中：accent 文字 + accent-soft 底色，辅以选中属性、字重或下划线；brand 只用于小面积强调。品牌色不代表错误。
- 焦点：focus 色 2px 外描边、偏移由 `--ab-focus-offset`（3px）统一管理；在主按钮周围保留纸面间隔。焦点不与 hover / selected 混为一谈。
- 成功、警告、错误保留对应浅底、文字与符号；禁用沿用原生 disabled 状态，不仅靠变浅区分。
- 一个视口只保留一个主要实心 CTA。标题默认 ink，正文链接用 accent 并保留下划线；不把每个标题、分类、分隔线都染粉。
- 不用六种鲜艳颜色区分六类资讯。不通过全局滤镜改变照片或品牌图形。

### 4.4 Logo 与 Icon 使用

| 资产 | 项目路径 | 适用位置 |
| --- | --- | --- |
| 用户 icon.svg | `assets/brand/icon.svg` | 浏览器标签页 favicon 等小尺寸网站缩略图标 |
| 用户 logo.svg | `assets/brand/logo.svg` | 页面刊头、页脚等平台品牌位置；与现有 Abe-spresso 字标组合 |

- 两份源图均为 228×228、1:1 SVG。保持 `object-fit: contain`，不拉伸、裁剪、换色、加阴影或使用 CSS filter。
- 页面 Logo 标准 44×44px，手机与页脚 32×32px；Logo 与相邻字标间距至少 Logo 宽度的 1/4。品牌链接点击区域仍 ≥44px，不把 Logo 尺寸等同于触控尺寸。
- icon 面向 16/32px 等缩略场景；不得反过来将完整咖啡杯 Logo 塞入 favicon，或把 Icon 代替刊头 Logo。样板可并排展示两者，但必须标用途。
- Logo 与可见字标同处一个链接时 `alt=""` 避免重复朗读；独立 Logo 链接需提供平台名称。原图里的 A 字形不改变 Barlow + Noto Sans SC 的 UI 字体规范。
- 本轮提供 SVG favicon；没有生成 Apple touch icon、社交分享封面或 PWA 全套图标，不宣称这些场景已适配。

### 4.5 形状与通用图标

- 内容图片/版块圆角 0；控件 4px；对话框 8px。不用巨大胶囊按钮和悬浮卡片。
- 通用 UI 图标统一线性，20×20、描边 1.75；品牌 SVG 不受线性图标规则约束。图标按钮点击区域 ≥44×44，必须有可访问名称。
- 常规资讯无投影、无渐变、无毛玻璃、无纹理背景；仅弹窗/菜单使用 Token 阴影。旧媒体遮罩样式不等于允许新增装饰渐变。

## 5. 网格与间距

### 5.1 尺度

仅使用 4/8/12/16/24/32/48/64/96px 对应的间距 Token。1/2px 仅用于边框；44px 是点击目标，20px 是图标，图片比例不受间距刻度限制。

| 场景 | 规范 |
| --- | --- |
| 标题与分类 / 摘要 | 8–12px |
| 摘要与来源 / 操作 | 12–16px |
| 条目内分组 | 16–24px |
| 速览上下 padding | 各 24px |
| 栏间距 | 手机 16 / 平板 24 / 桌面 32px |
| 主要区块间距 | 手机 32 / 平板 48 / 桌面 64px |

### 5.2 响应式

| 范围（CSS 宽度） | 外边距 | 设计网格 | 阅读结构 |
| --- | --- | --- | --- |
| `<48rem`（768px） | 16px | 4 栏 | 单列，主新闻 → 其余精选 → 速览 |
| `48rem–<75rem` | 24px | 8 栏 | 精选可 5:3，两列内容最低宽度须可读；不够则堆叠 |
| `≥75rem`（1200px） | 至少 48px | 12 栏 | 容器最大 1200px，主新闻/其余精选 7:5 |

网格是对齐工具，不要求同时显示 12 列内容。页眉、导航、主内容、页脚共用同一容器；详情正文居中收窄到 720px。业务页面已移除 `570/850/1100px` 旧断点；使用 48rem 与 75rem 两档，不在手机上缩小正文。

- DOM 顺序必须就是阅读顺序，不通过 CSS `order` 换序欺骗视觉。
- 手机取消非必要侧栏，筛选放入可折叠面板；保留名称、摘要、资料、已读/收藏。
- 不固定页头高度来裁切放大文字；非必要不 sticky。若 sticky，锚点滚动偏移需对应真实高度，不挡键盘焦点。
- 320px 不出现页面级横向滚动；表格和代码块可以在有名称的独立容器内横滚。
- 验收宽度：320、375、768、1024、1440；两种语言；200% 缩放；400% 回流专项检查。

## 6. 内容与组件契约

### 6.1 全局导航

固定 Today / Archive / Saved 三个目的地。当前语言只显示一套标签。导航用链接及 `aria-current="page"`，不能把普通页面导航伪装成 ARIA tab。选中态为文字强调 + 2px 下划线，不只靠颜色。

### 6.2 日报信息与进度

期号、日期、示例/更新状态属于同一组；`已读 3 / 12` + 一条进度 + 一个继续入口。进度拥有可访问名称。无刷屏数字看板、重复侧栏目录、假“实时”绿点。完成整期必须确认；完成后可逐条恢复未读，不暗示存在一键撤销整期操作。

### 6.3 精选条目 FeaturedStory

顺序：内容类型 / 技术主题 → 标题链接 → 主题图（可选）→ 原文短摘录 → 来源/时间/阅读时长 → 已读/收藏。

- 主新闻仅一条，使用 lead 字号和 16:9 配图；其余精选使用 title 字号。卡片不展示或要求生成独立的“为什么重要”字段；详情页章节不受此调整影响。
- 标题链接和收藏按钮是兄弟节点，禁止整卡 `<a>` 套 `<button>`。
- 默认无卡片外框，不靠 hover 抬升。hover 标题下划线；focus 有可见轮廓。
- 类型、主题、来源角色是三种不同字段，不混为一排无语义彩色标签。

### 6.4 速览 QuickStory

序号 + 标题 + 原文短摘录 + 来源 + 操作。默认无图，不为了凑视觉密度强制配图；若内容包含视频，以按需视频入口附在该条，不再新增独立“今日视频”栏目。

### 6.5 按钮与表单

| 变体 / 状态 | 规则 |
| --- | --- |
| primary | 深莓底白字，用于当前主要任务；不得使用亮洋红底承载普通白字 |
| secondary | 中性边界，用于收藏、确认之外的次操作 |
| quiet | 透明底，仍有完整点击区域 |
| hover / focus / pressed | 背景反馈 / 蓝色轮廓 / `aria-pressed` + 可见状态文字 |
| disabled | 原生 `disabled`，弱底色；不能仅降低透明度并仍响应 |
| loading | 保留宽度、文字改为“处理中…”，`aria-busy`，阻止重复提交 |
| input | 16px 字号、≥44px 高、持久 label；placeholder 不能替代 label |
| error | `aria-invalid` + `aria-describedby` + 明确修复方式，不能只有红边 |

收藏/已读是两个独立 toggle：可见标签和 `aria-pressed` 同步。切换后焦点保持在原操作；用 `role=status` 温和反馈，不每次弹窗。异步失败应回滚乐观状态并可重试。

### 6.6 筛选、搜索、空状态

- 筛选标签明确“内容类型 / 技术主题”；类型与主题取交集；有“清除筛选”，显示结果数，不改编辑顺序。
- 搜索无结果：显示查询词与清除入口，保留用户输入；不可用别的新闻填充。
- Saved 空状态：说明“还没有收藏”，链接到当期；非游客必须能区分“未登录”和“没有收藏”。
- Archive 空月份：说明该月份没有已发布日报；不可伪造条目。
- 加载失败：具体说明受影响内容，保留已有数据和重试入口；不得把失败显示为真实空列表。

### 6.7 弹窗与提示

使用原生 `<dialog>` + `showModal()`，标题关联、初始焦点、ESC、关闭按钮、关闭后归还触发按钮焦点。不要手写假遮罩而遗漏焦点管理。内容过长内部滚动，320px 不溢出。成功消息不抢焦点；错误持续到用户处理，不能 1 秒自动消失。

### 6.8 图片、视频、来源与可信度

- 主新闻、详情和视频图 16:9，辅助精选小缩略图 3:2；显式 width/height 或 aspect-ratio 预留空间，不能拉伸。
- 新闻图、示意图、生成图必须区分；主题配图写清楚“主题配图，非事件现场”，记录来源与许可。禁止暗示图库图片就是现场证据。
- 图片失败：保留比例、展示中性占位及说明，不出现破图标覆盖标题。含文字的概念图须能放大或提供文本等价信息。
- 首屏关键图不 lazy；其余延迟加载，视频点击同意后再嵌入，禁止自动播放。
- 来源角色明确为原始公告 / 论文 / 仓库 / 媒体报道 / 编辑解读；延伸阅读不能伪装成事实证据。
- 来源名、原始发布时间、日报收录日期、更新说明不同字段展示；缺失时间写“原始时间待核验”，不得用收录时间冒充。
- AI 整理内容标注整理属性和核验状态，不编造核验人数或准确率。

## 7. 页面模板

### Today

```text
品牌与搜索/语言/账户
主导航
期号与日期 + 示例状态
一行阅读进度
Top 5：一条主新闻 + 其余精选（4条）
7 条速览
本期完成反馈 + 往期入口
页脚
```

不额外插入营销 Hero、无关统计卡、第二条进度和重复视频。筛选是辅助操作，不抢主新闻位置。

### Detail

返回入口 → 类型/主题 → 原文 h1 → 发布方直链/真实发布日期 → 原文短摘录 → 来源角色与核对范围 → 可选延伸资源（明确与新闻的关系）→ 独立已读和收藏 → 前后条目。不保留模型生成的 what/why/how/impact 章节。

### Archive

h1 → 月份筛选 → 日报列表（日期、精选摘要、12条标识、已读进度）→ 分页/月份导航。既有历史快照不随“当前期”内容被覆盖。

### Saved

h1 → 本机/账户保存范围说明 → 收藏列表（来源日报、原始资源、收藏状态、独立已读）→ 真正的空状态。取消收藏后的列表更新需有撤销或合理焦点去向。

### v1.2 阅读效率与新闻呈现补充契约

1. **标题先于配图。** DOM顺序为分类/编号 → 标题 → 图片（可选）→ 摘要 → 资料/时长/操作；不以CSS换序。主新闻使用16:9配图，辅助精选用 `--ab-width-thumbnail` 小图。示意性质必须可见，照片不是事实证据。
2. **三种阅读密度。** 主标题使用lead尺度；其余精选/速览标题使用title尺度。Top 5保留原文摘录，不再增加独立价值说明。7条速览默认一段短摘录，不能通过复制解释让速览变成长文。
3. **宽屏速览两区，不是两条信息流。** ≥75rem每条左侧是标题/摘要，右侧是资料与操作；移动端回到同一条目内纵向流。07永远跟随06，不能用CSS列重排阅读顺序。
4. **资料而非背书。** 真实来源使用“原文 / Original”前缀并直达具体文章；标题打开站内详情。详情显示发布方、真实发布日期，来源角色与核对范围在可展开说明中保留。缺失摘录不回退到模型摘要，缺失时间不以期号代替。不增加虚构发布时间、热度、突发标签或核验人数。
5. **删的是噪声，不是功能。** 顶部保留示例及本机范围说明；每期只有一个进度条和阅读入口。账户入口称“本机演示 / Local demo”，不暗示已有在线注册服务。导航、主题、来源、收藏、已读和视频在手机上都保留。
6. **筛选与焦点有上下文。** 筛选后目录指向筛选结果，不留下不存在的速览锚点。取消收藏后焦点去下一条收藏按钮，列表为空则去main；弹窗结束且触发按钮被重绘时恢复到同语义控件，控件不存在则去main。
7. **新增Token职责。** `--ab-text-brand`用于刊头；`--ab-width-thumbnail`用于小图；`--ab-width-story-meta`用于宽屏资料区；`--ab-width-media-dialog`用于播放器弹窗；`--ab-width-progress`用于唯一进度条；`--ab-focus-offset`统一焦点偏移。容器宽度仍仅取page/reading，不可另造1120/1280px容器。

## 8. 实现约束与生成规则

加载顺序：`design/tokens.css` → `design/components.css` → `styles.css` → `architecture.css`。`styles.css` 负责站点外壳、共用控件与浮层；`architecture.css` 负责编辑布局和页面组件；二者不是先定义后覆盖的补丁关系。组件通过 `.ab-*` 命名空间复用；不要把样板专属 `.sg-*` 布局当成业务组件。

- 颜色、字体、间距、字号、圆角必须来自语义 Token；新增 Token 要写明角色及使用场景。
- 不用行内 style 堆业务样式，不追加第三份全局 override，不用 `!important` 修复级联；修改组件源定义。
- v1.2 已将旧样式按组件归位，删除无 DOM 使用的侧栏/旧筛选/独立视频栏样式；继续维护源定义，不允许重新追加全局覆盖。
- 控件身份和数据字段稳定；切换语言不清空状态。不要把固定示例日期自动更新成今日日期。
- 只为功能必需加入 JavaScript。没有轮播、自动滚动和装饰动画；必要反馈 120/180ms，支持 reduced-motion。
- 当前仅有浅色主题，不输出未经核验的“自动暗黑模式”。颜色 Token 预留语义，不代表暗色方案已设计。

### 可复制的原型生成指令

> 为 Abespresso 生成/修改页面前，读取 AGENTS.md、design/DESIGN-SYSTEM.md 和 design/tokens.css。采用 Barlow + Noto Sans SC 无衬线字体栈，保持品牌洋红、深莓行动色与暖咖啡中性色的新闻编辑式布局；正文至少 16px，详情 18px，元数据 14px，禁止衬线标题、9–11px 小字、渐变和悬浮卡片。复用 .ab-* 组件及 Token，不新增全局覆盖文件。保留 Top 5 + 7、Today / Archive / Saved、来源与示例说明、独立收藏与已读。输出前检查双语、响应式、键盘和真实空/错状态，并明确本次未覆盖的旧代码。

## 9. 验收与迁移优先级

### 阻止交付的检查

- [ ] 标题/正文全部无衬线；英文字体优先；断网中文可读。
- [ ] 一个页面一个 h1；结构 h1 → h2 → h3，无假按钮/嵌套交互。
- [ ] 正文 ≥16px、详情18px、操作和来源≥14px；12px只用于指定注释。
- [ ] 对比度符合指定配对目标；焦点边界可见；状态不仅靠颜色。
- [ ] 点击区域≥44px；键盘能使用筛选/搜索/收藏/已读；弹窗 ESC 与焦点恢复。
- [ ] 320/375/768/1024/1440 双语无页面级横向滚动；缩放200%可操作；400%回流检查。
- [ ] 空数据、缺图、加载、长标题、长来源、失败/重试已覆盖；不使用假成功。
- [ ] 示例/真实新闻、来源时间/收录时间、收藏/已读没有混淆。
- [ ] 无重复主 CTA、进度、来源操作；没有裁切关键新闻信息。
- [ ] 变更说明区分自动检查、实际浏览器检查、未验证事项。

### v1.2 迁移台账

| 优先级 | 项目 | 当前状态 |
| --- | --- | --- |
| P1 | 9–12px 正文/元数据、手机缩字 | 业务组件改为正文16px、详情18px、元数据/控件14px；运行时五宽度检查 |
| P1 | 重复覆盖、旧断点、不一致容器 | 原定义归位；共用1200px容器与48/75rem断点；移除业务 `!important` |

| P1 | 小点击目标、弹窗或取消收藏后丢失焦点 | 44px控件、共享可见焦点、重渲染后逻辑焦点恢复；浏览器回归 |

## 10. 原文详情阅读器补充（2026-09-19）

最新用户要求扩展详情的全文/插图能力，不改变首页卡片内容契约。详情采用阅读宽度、原文顺序、可折叠章节目录和来源/转载说明；无可用全文时显示真实摘录状态。文内图保持比例且保留图注/署名，缺图显示占位说明；禁止用主题图冒充原图。正文18px，说明和控件至少14px；段落、表格、代码、引文及文内链接使用现有Token。目录定位不改动业务路由；已读/收藏保持独立。完整数据与授权边界见 [ARTICLE-READER.md](ARTICLE-READER.md)。
